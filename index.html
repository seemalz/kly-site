// the solution

Three machine-readable primitives.

Simple API calls. Pay-per-use via MPP (Machine Payments Protocol) and x402.

Identity Layer

Every agent gets a Decentralized Identity (DID) — a unique, blockchain-anchored identifier that lets agents manage their own identities and operate across platforms without relying on a central authority. Each DID is linked to the deploying business (KYB) and human principal (KYC). Signed credentials any counterparty can verify. Trust on first contact, no human needed.

Expense Management

Pre-funded treasuries replace shared corporate cards. Spend is physically bounded. Velocity alerts catch runaway agents in minutes. Idle treasury earns yield. Every transaction memo-indexed on-chain.

AP / AR

Buyer agents: escrow-backed POs, LLM-judged delivery, streaming payments with kill switch. Supplier agents: auto-invoice on delivery, proof of work on-chain, reputation-tiered payment speed.

// see it in action

Three API calls. That's it.

Identity, treasury, settlement — a complete agent transaction in seconds.

agent@kly ~ /transaction
$ kly.identity("did:kly:agent-0x7f3a") // verify DID, return signed credential
$ kly.treasury(agent, { max: "$500", daily: "$2000" }) // check balance + policy
$ kly.pay(vendor, 250, { escrow: true }) // escrow → judge → settle
✓ settled $250.00 → vendor-0x9b2c | rep +1 | tx 0x8a3f...c7d1
